# UTS-Pemrograman-Berbasis-WEB
Deskripsi Singkat:
Program ini adalah website sederhana untuk mengelola data mahasiswa. Website ini dibuat menggunakan HTML untuk struktur tampilan, CSS untuk desain, dan JavaScript untuk menjalankan fungsi programnya. Di dalam program ini pengguna bisa menambahkan data mahasiswa seperti NIM, nama, alamat, jenis kelamin, dan password. Data yang sudah diinput akan langsung tampil di tabel.

Program ini juga memiliki fitur edit untuk mengubah data mahasiswa dan fitur hapus untuk menghapus data yang sudah tidak diperlukan. Selain itu ada fitur pencarian supaya pengguna lebih mudah mencari data berdasarkan NIM atau nama mahasiswa.

Data mahasiswa disimpan menggunakan localStorage sehingga data tetap tersimpan walaupun halaman website di-refresh atau ditutup. Tampilan website juga dibuat lebih menarik dengan adanya fitur dark mode untuk mengganti tampilan menjadi mode gelap dan terdapat fitur cetak PDF untuk mencetak data mahasiswa. Website ini dibuat agar pengelolaan data mahasiswa menjadi lebih mudah, cepat, dan rapi.
